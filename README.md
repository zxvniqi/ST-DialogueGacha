# 대사 가챠 (ST Dialogue Gacha)

지금 열려 있는 채팅에서 대사 하나를 랜덤으로 뽑는 재미용 가챠 확장입니다. 다른 확장 없이 단독으로 동작합니다.

## 사용법

1. 채팅 입력창 왼쪽 **마법봉 메뉴 → 대사 가챠** (또는 슬래시 명령 `/dgacha`)
2. 뜨는 창에서 **뽑기!** 버튼

카드가 두근두근 흔들리다 뒤집히면서 대사가 나옵니다. 흔들리는 동안 카드를 누르면 바로 열립니다.
**뽑기!** 를 다시 누르면 한 번 더, **이미지 저장**을 누르면 카드를 정사각형(1:1, 1080×1080) PNG 사진으로 저장합니다.

뽑은 대사는 이렇게 나옵니다.

```
"대사"

봇 이름, #메시지 번호
```

## 설정 (가챠 창 아래 "설정"을 펼치기)

| 항목 | 설명 |
|------|------|
| 대사 기호 | `"큰따옴표"`(“ ” 포함), `「낫표」`(『 』 포함) 중 선택, 둘 다 가능 |
| 숨긴(눈 감은) 메시지 포함 | 숨김 처리한 메시지의 대사도 뽑을지 |
| 내(유저) 대사 포함 | 유저 메시지의 대사도 뽑을지 |
| 최소 글자 수 | 이보다 짧은 대사는 제외 ("응" 같은 짧은 대사 거르기) |
| 먼저 보일 버전 | 번역 확장으로 번역한 메시지에서 번역본(화면에 보이는 글) / 원문 중 무엇을 먼저 보여줄지. 뽑은 뒤에도 카드 아래 **원문 보기 / 번역본 보기** 버튼으로 바로 바꿔 볼 수 있어요 |
| 스타일 | 웹소설 발췌(밝은 종이) / 어두운 카드 |
| 글꼴 | 스타일 기본 / 명조·고딕(기기 내장) / 실리 채팅 글꼴 / 무료 글꼴 30종(나눔손글씨, 고운바탕, 감자꽃, 주아, 도현 등). 목록에서 각 글꼴이 그 모양으로 미리 보여요 |
| 글씨 크기 | 60%~160%. 대사가 길면 카드에 맞게 알아서 줄어들어요 |
| 색 직접 정하기 | 배경색, 글자색 직접 지정 |
| 배경 이미지 | 내 사진을 카드 배경으로. "이미지 흐리게"로 글씨가 잘 보이게 조절 |
| 뽑기 연출 | 끄면 애니메이션 없이 바로 결과 |

코드 블록이나 상태창(`<details>`, `<table>` 등) 안의 글은 뽑지 않습니다.

무료 글꼴은 저작권 걱정 없는 오픈 라이선스(SIL OFL) 글꼴을 Google Fonts에서 불러옵니다. 고른 글꼴만, 필요한 글자만 내려받아서 가볍고, 인터넷 연결이 필요해요.
배경 이미지는 이 브라우저에만 저장됩니다(설정 파일을 무겁게 만들지 않도록).
